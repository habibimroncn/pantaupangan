Solusi Bypass CORS Server Pemerintah

Hubungkan melalui Relay Proxy atau Cloudflare Worker Anda

Mengapa CORS terjadi? Server pemerintah (Bapanas/Kemendag/BI) hanya mengizinkan akses dari domain resmi mereka dan memblokir permintaan langsung dari browser pihak ketiga.

Solusi Otomatis: Aplikasi ini otomatis mencoba 4 Public CORS Relay secara paralel. Jika semua proxy publik dibatasi rate-limit, masukkan URL Cloudflare Worker gratis Anda di bawah ini:

Kode Cloudflare Worker Gratis (100.000 req/hari): 
export default {
  async fetch(req) {
    const target = new URL(req.url).searchParams.get("url");
    if (!target) return new Response("Missing url", { status: 400 });
    const res = await fetch(target, { headers: { "User-Agent": "Mozilla/5.0" } });
    const headers = new Headers(res.headers);
    headers.set("Access-Control-Allow-Origin", "*");
    return new Response(res.body, { status: res.status, headers });
  }
};
